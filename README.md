# 易经占卜

单页罗盘交互的易经占卜应用：旋转罗盘出卦、浏览 64 卦、卷轴展示卦辞爻辞解读。

## 技术栈

Vue 3 + Vite + vue-router，纯 CSS/SVG，零 UI 依赖。

## 命令

```bash
pnpm dev                          # 启动开发服务器
pnpm build                        # 生产构建至 dist/
pnpm preview                      # 预览生产构建
node scripts/verify-hexagrams.mjs # 验证卦象数据完整性
```
