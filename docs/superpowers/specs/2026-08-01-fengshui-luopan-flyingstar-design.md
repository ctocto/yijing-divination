# 风水罗盘 + 宅运飞星盘 设计文档

日期：2026-08-01
状态：已与用户头脑风暴收敛并批准

## 背景与目标

现有《周易》挂图 App（伏羲六十四卦方圆图 + 起卦）希望加入风水功能。经讨论确定形态：

- **形态**：全屏独立功能页（与「浏览六十四卦」同为 overlay，从挂图底部入口进入），延续挂轴/宣纸/金石美学。
- **核心价值**：不是摆设，而是「输入 → 有用结论」的分析功能——旋转罗盘选方向 → 出 3×3 宅运飞星盘 + 断语。
- **断语深度**：中版——九星表（当运/失令）+ 大局判断（旺山旺向等）+ 特殊位（财位/文昌/病符/五黄）+ 每宫分档白话。
- **坐向口径**：坐山/朝向可切换（用户决定红针标哪个；山盘/向盘始终用坐山/朝向计算）。

## 决策摘要

| 决策点 | 结论 |
|---|---|
| 功能形态 | 全屏 overlay 独立页（同卦库模式） |
| 核心流程 | 旋转罗盘选方向 → 3×3 飞星盘 + 断语 |
| 断语深度 | 中版（九星本性 + 旺衰 + 大局 + 特殊位，不写 81 组合全表） |
| 坐向口径 | 坐山/朝向可切换 |
| 元运 | 1-9 段选，默认九运（2024-2043） |

## 算法设计（`src/utils/fengShui.js`，纯函数）

盘面用宫数组 `[巽,离,坤, 震,中,兑, 艮,坎,乾]`（3×3 按行展开，index 映射宫）。

- 洛书飞布宫位序列：`中→乾→兑→艮→离→坎→坤→震→巽`。**顺/逆不改变宫位顺序，只改变星数增减**：顺飞 +1 递增、逆飞 −1 递减。
- `yunPan(period)`：元星入中顺飞。
- `shanPan(shan, yunPan)`：坐山宫位的运星入中。顺逆按**同元龙法**：
  - 入中星 ≠ 5：查该星元旦盘原卦（1坎 2坤 3震 4巽 6乾 7兑 8艮 9离），取原卦三山中与坐山同元龙的一山，其阴阳定顺逆（阳顺阴逆）。
  - 入中星 = 5：五黄无原卦，依坐山本身阴阳定顺逆。
  - `xiangPan` 同理用向首。
- `buildPan(shan, xiang, period)` → `{ yun, shan, xiang }`。
- `overallJudge(pan, period)`：按「山盘旺星落坐山/向首宫、向盘旺星落坐山/向首宫」四象限判大局；检测伏吟（星数=宫数）、反吟。
- `specialPositions(pan, period)`：财位（向星为旺星/生气星之宫）、文昌（四绿宫）、病符（二黑宫）、五黄（五黄宫）。
- `palaceJudges(pan, period)`：每宫按（运/山/向星）+ 旺衰给 `{ level, brief白话 }`，模板化生成。

> 重要：勿用简化的「坐山阴阳定顺逆」规则，会错判（如八运乾山巽向会从旺山旺向误判为上山下水）。

## UI 设计

### 全屏页 `FengShuiView.vue`

竖屏上下布局：页头（标题+关闭）→ 可旋转罗盘 → 口径切换 + 元运段选 + 读句/大局 banner → 3×3 飞星盘 → 滚动解读区。横屏可左右分栏。

状态用局部 ref：`mode`、`selectedDir`（指针所指 24 山）、`period`（默认 9）。`shan`/`xiang` 由 `selectedDir` + `mode` 派生，computed 调 `buildPan`。

### 罗盘 `Luopan.vue`

SVG 同心环：外环 24 山名（每 15°），内环八卦方位 + 洛书数（复用 `trigrams.js` 的 `direction`/`num`）。顶部固定红针、对宫金点。拖拽旋转（pointer 事件）+ 点按选中，吸附到最近 15° 山位。`emit('select', mountainName)`。

### 盘面 `FlyingStarPan.vue`

3×3 洛书格（离上坎下），每格按传统「运/山/向」约定排三星，吉凶色标档位，特殊位叠加角标（财/文/病/煞）。中央宫特殊处理。

## Home.vue 改动

底部按钮行加「风水罗盘 ▸」，`showFengShui` ref 控制 `<FengShuiView>` overlay（与 `HexagramLibrary` 并列）。

## 验证

1. `scripts/verify-fengshui.mjs` 结构不变量：24 山数量/每宫三山/15° 连续/三元龙阴阳口诀一致；每盘为 1-9 排列；运盘中心=元运；阳顺阴逆抽样。
2. 已知案例回归（已手算验证，实现时对照排盘资料最终核对）：
   - 五运子山午向 = 旺山旺向（山星1逆、向星9逆，旺星5双到山向）。
   - 八运乾山巽向 = 旺山旺向（山星9逆、向星7逆）——区分同元龙法 vs 简化法。
   - 七运子山午向 = 全局合十（每宫运星+山星=10）。
   - 九运子山午向：山星5逆、向星4顺。
   - 一运、九运无旺山旺向之局。
3. UI 走查（`pnpm dev`）：旋转/点按联动、口径切换反推、元运刷新、移动端、减弱动效、断语覆盖。
