# 罗盘易卦抽爻 + 择日（P4）设计文档

日期：2026-08-02
状态：已与用户头脑风暴收敛并批准（用户选定：易卦=交互抽爻换象；择日=读盘直断 + 建除十二神 + 黄道黑道）

## 背景与目标

P3 三合判断（P3a 消砂 + P3b 纳水）已合入 main。P1 多圈罗盘现有五个模式，其中「易卦」「择日」两模式仍只有读数、判断区为占位文案（`pendingText`：`抽爻换象 · P4 上线` / `择日输出 · P4 上线`）。本文档实现 **P4 易卦 + 择日**：把这两个判断区从占位变真断语。

- **易卦**：十字线读出坐向卦（本卦），判断区交互抽一爻为动爻 → 该爻阴阳翻转 → 得变卦 → 断语 = 动爻爻辞 + 变卦卦辞/白话。
- **择日**：十字线读出节气 + 六十甲子（含纳音），判断区输出该「日」的建除十二神 + 黄道黑道 + 纳音 + 宜忌。

## 算法口径（已查证，主流黄历口径）

### 易卦 · 抽爻换象

六爻卦以六位二进制表示（`'1'`=阳爻、`'0'`=阴爻），**自下而上**（初爻在首位）。抽一爻动 = 翻转该位。动爻按位序得爻名（初九/九二/…/上六，阴阳看爻值）。断语链路：

```
本卦（十字线读卦）→ 点选动爻 → 爻翻转 → 变卦
断语 = 本卦卦辞 + 动爻爻辞 + 变卦卦辞/白话
```

现有 `src/data/hexagrams.js` 每条已含 `binary`/`name`/`text`（卦辞）/`plain`（白话）/`lines[6]`（爻辞，带「初九：」等爻名前缀），**直接复用，无需新数据**。爻辞按索引对齐：`lines[0]`=初爻、`lines[5]`=上爻。

### 择日 · 建除十二神 + 黄道黑道

- **月建**：由节气定月建支（二十四节气分十二建月）。十字线可能落在任一节气（含中气），故月建覆盖全部 24 节气——十二「节」各自起一月，各「中气」与所属节同月：
  ```
  立春→寅 雨水→寅 惊蛰→卯 春分→卯 清明→辰 谷雨→辰
  立夏→巳 小满→巳 芒种→午 夏至→午 小暑→未 大暑→未
  立秋→申 处暑→申 白露→酉 秋分→酉 寒露→戌 霜降→戌
  立冬→亥 小雪→亥 大雪→子 冬至→子 小寒→丑 大寒→丑
  ```
  （节气按三合盘口径与十二地支宫对齐，非公历月；`termMonth` 为 24 条全表，中气与节同支。）

- **日支**：六十甲子名末字即日支（甲子→子、乙丑→丑…癸亥→亥）。

- **建除十二神**：月支起「建」，按十二支顺序顺数到日支得当日神（建/除/满/平/定/执/破/危/成/收/开/闭）：
  ```
  建 除 满 平 定 执 破 危 成 收 开 闭
  子 丑 寅 卯 辰 巳 午 未 申 酉 戌 亥
  ```

- **黄道黑道**：与建除同一序差，十二神煞一一对应（建=青龙、除=明堂、满=天刑、平=朱雀、定=金匮、执=天德、破=白虎、危=玉堂、成=天牢、收=玄武、开=司命、闭=勾陈）。黄道吉（青龙/明堂/金匮/天德/玉堂/司命），黑道凶（天刑/朱雀/白虎/天牢/玄武/勾陈）。

> 建除与黄道黑道同源：一次算序差，两套呈现。

## 范围边界（P4 明确不做，记录备后续）

以下**本版不做**，仅记录方向：

1. **黄历完整神煞**（冲煞/岁破/诸事不宜等复杂神煞系统）——只用建除十二神 + 黄道黑道两套主口径。
2. **六爻装卦/世应/用神**——抽爻换象只到「动爻爻辞 + 变卦卦辞」，不做完整六爻占断。
3. **择日接真实日历**（公历日期→干支换算、输入具体日期）——维持纯读盘直断，不与真实日历对接。
4. **干支纪年/纪月/纪时输出**——只断「日」的建除/黄道，年/时干支不做。
5. **易卦抽爻与分金结合**（抽爻换象在风水中常与 120 分金配合定卦气）——P2 分金另独立阶段。
