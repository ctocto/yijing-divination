日期：2026-08-03
状态：按 docs/TODO.md 首条待办实施完成。口径参考流行做法（正针七十二龙 + 平分六十龙），吉凶口径与现有分金统一。

## 背景与目标

优先级计划 Phase 3：**分金 / 穿山 / 透地 共用一圈位**（同半径 212），一次只显示一个，默认分金。理由：移动端盘面宽度受限（viewBox 保持 540 不加圈），圈位切换不增加屏上圈数密度，手机与桌面体验一致。

本版实现两张立向龙神圈的数据 + 吉凶 + 圈位切换 UI + 十字线读数，让用户能读来龙干支与吉凶。

## 算法口径（已查证流行做法）

### 穿山七十二龙（正针穿山虎 · 地纪）
- 72 槽 × 5°，每山 3 龙。60 甲子 + 12 **大空亡**（八干四维正中，罗盘标"正"或留空）。
- **甲子起地盘正针壬山最末一格**（[347.5,352.5)，中心 350°），顺行（角度增大）排列。
- **支分组排布**：
  - 地支山 = 丙/戊/庚（阳支：子寅辰午申戌）或 丁/己/辛（阴支）。
  - 干维山 = [前支组后边干, 大空亡, 后支组前边干]。例：子山=丙子戊子庚子；壬山=癸亥·空·甲子；癸山=壬子·空·乙丑。
- 吉凶复用分金口径（八卦纳甲九六冲合）：**旺相**(丙丁庚辛)吉 24 位；孤(甲壬)/虚(乙癸)/龟甲(戊己)/大空亡 凶。
- 命中验证：坐子正中（0°）→ 戊子龟甲空亡凶，与口诀「地支子山中间戊子龙为差错空亡」一致。

### 透地六十龙（平分六十龙 · 天纪）
- 60 龙 × 6°，**甲子起正针壬初**（337.5°，中心 340.5°），六十甲子连排。
- 双山五行分组（壬子双山管 5 龙）：[337.5,7.5) = 甲子乙丑丙寅丁卯戊辰。✓
- 吉凶 = **杨公五气脉**（甲子序每 12 一组）：

| 组 | 甲子序 | 气脉 | 位 | 吉凶 |
|---|---|---|---|---|
| 甲子旬 | 0-11 | 冷气脉 | 孤 | 凶 |
| 丙子旬 | 12-23 | 正气脉 | 旺 | **吉（珠宝）** |
| 戊子旬 | 24-35 | 败气脉 | 煞（火坑） | 凶 |
| 庚子旬 | 36-47 | 旺气脉 | 相 | **吉（珠宝）** |
| 壬子旬 | 48-59 | 退气脉 | 虚 | 凶 |

- 珠宝 = 24 位（丙子/庚子二旬），与文献一致。命中验证：坐子正中（0°）→ 丁卯（冷气脉·孤凶）。

## 数据设计

### 新增 `src/data/long.js`（+ `long.d.ts`，纯数据，node 可校验）
- `chuanShan72`：72 槽 `{ name, gan, zhi, level, ji, nian, angle }`（name 空串 = 大空亡，保留用于查找）。按上述支分组规则从 `mountains` 生成；`level` 复用 `fenjin.js` 导出的 `LEVEL_BY_GAN`（甲壬孤/乙癸虚/戊己龟甲/丙丁庚辛旺相），大空亡槽 `level='大空亡' ji='凶'`。
- `touDi60`：60 龙 `{ name, nian, qi, level, ji, angle }`。`qi=['冷','正','败','旺','退'][⌊i/12⌋]`，`level=['孤','旺','煞','相','虚'][…]`，`ji = ⌊i/12⌋∈{1,3} ? 吉 : 凶`；`angle=(jiazi[i].angle+340.5)%360`。

### 读数 `src/utils/luopanRead.js`（+ `.d.ts`）
- `chuanShanAt(deg)` / `touDiAt(deg)`：复用现有 `itemAt` 最近角度取槽（返回整槽，含吉凶/纳音/五气）。

## 圈位切换（渲染层）

### `src/data/luopanRings.js`（+ `.d.ts`）
- `RING_TYPES` 增 `chuanShan` / `touDi`：`{ type:'labels', radius:212, labelSize:10 }`（与 `fenjin` 同槽位）。d.ts `RingId` 补三缺漏（含 `fenjin`）。

### `src/components/fengshui/Luopan.vue`
- props 增 `ringSlot`（默认 `'fenjin'`）。
- `activeRings`：定向模式把数组里的 `'fenjin'` 换成 `ringSlot`（一次只渲染一圈，不增屏上圈数）。
- `ringItems` 增 `chuanShan` / `touDi` case：60 干支全标（穿山过滤大空亡槽），`tone` 吉金/凶暗，十字线所在槽 `active` 高亮。
- snap step 保持 ding 3° 不变（十字线落在 5°/6° 槽内按最近龙读数，正确）。

### `src/components/fengshui/RingLayer.vue`
- labels 分支 text 支持 `tone`：`.label-ji`（金色）/`.label-xiong`（暗 55%）；`.label.active` 补 `opacity:1` 防被 tone 压暗。分金项无 tone，不回归。

## UI（`src/components/fengshui/FengShuiView.vue`）

- 圈位切换控件：`ringSlot` 状态 + 「分金 / 穿山 / 透地」三分段（复用 `.mode-toggle` 样式），置于定向模式坐山/朝向切换之后。
- 读数：`.readout` 定向分支按 ringSlot 显示坐/向龙名 + 吉凶（大空亡显示「大空亡」）。
- 判断区（fs-fenjin）：标题随槽位（分金吉凶 / 穿山七十二龙 / 透地六十龙）；分金保留仙命 + 坐向分金原样；穿山/透地显示坐/向龙（名·纳音·吉凶；透地附五气脉）。复用 `.fj-row`/`.fj-level`/`.fj-gold`/`.fj-bad` 样式。
