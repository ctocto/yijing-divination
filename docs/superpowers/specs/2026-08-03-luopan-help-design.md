# 应用内操作手册（帮助页）设计文档

日期：2026-08-03
状态：已与用户确认（应用内帮助页 + 整个应用全覆盖）。实现完成：`HelpPanel.vue` 全屏帮助弹层，主页面 + 风水罗盘双入口，10 章白话手册覆盖六爻起卦与罗盘五模式。

## 背景与目标

罗盘内大量专业词语、概念与功能（分金/旺相/龟甲/孤虚/大空亡/穿山龙/透地龙/元运/九宫飞星/消砂/纳水/建除/黄道/抽爻…）对非专业人士难以理解。用户（开发者本人）也反馈不少功能不知道如何使用。目标：**应用内**提供一份面向普通用户的操作手册，解释全部功能怎么操作 + 专业术语什么意思。

已拍板口径：**应用内帮助页**（不是独立文档）、**整个应用全覆盖**（六爻起卦 + 风水罗盘五模式）。

## 设计

### 入口（双入口）

1. **主页面** footer 新增「操作手册 ▸」按钮（复用 `.library-link` 样式，排在「风水罗盘 ▸」之后）→ 帮助弹层打开在开头。
2. **风水罗盘** header 新增「？」按钮（`aria-label="操作手册"`，紧挨关闭 ×）→ 帮助弹层**定位到当前模式对应章节**：`ding→定向`、`xiao→消砂`、`na→纳水`、`ze→择日`、`gua→易卦`（`FengShuiView` 持有 `helpSectionId` computed，`$emit('help', id)`，Home 转发为 `initialSection` prop）。

### 组件（`src/components/help/HelpPanel.vue`）

- 全屏弹层，结构镜像 `HexagramLibrary.vue`：根 `role="dialog"` + header（书法体标题 + 圆 × 关闭）+ 内容区。
- **z-index 50**——高于风水罗盘（z-40），保证罗盘内打开帮助时覆盖其上。
- header 下横向章节导航条（chip，`overflow-x:auto`），点击 `scrollIntoView` 到对应章节；`initialSection` prop 打开时自动定位（onMounted + nextTick）。
- 内容按章节渲染 `<section :id>`，`scroll-margin-top` 避免被导航条遮挡。
- 复用全局主题变量（`--paper/--scroll/--gold/--cinnabar/--ink…`），响应式：桌面内容居中限宽 760px，`max-width:600px` 缩 padding、导航横滚。

### 内容（`src/data/helpContent.js` + `.d.ts`）

结构化章节数组 `GUIDE`，块类型：`para` / `steps`（怎么用）/ `terms`（术语定义表）/ `table`（数据表）/ `note`（提示框）/ `list`。**写作原则**：全中文白话，每个术语一句话解释（可带生活类比），每个功能配「怎么用」步骤，全篇贯穿「文化参考、非专业建议」免责立场。

10 章：快速开始（含免责声明）/ 六爻起卦 / 罗盘总览（五种模式一表、坐山朝向、元运、三盘三针）/ 定向·立向分金（分金四档、穿山、透地、仙命）/ 宅运·九宫飞星（九星表、大局、特殊方位）/ 消砂 / 纳水 / 择日（建除十二神表、黄道黑道表）/ 易卦抽爻 / 术语速查（高频词汇总表）。

术语与吉凶口径与实现一致（建除/黄道照 `zeriData.js`，九星照 `flyingStars.js`，分金/穿山/透地照 `fenjin.js`/`long.js`）。

### 校验（`scripts/verify-help.mjs`）

GUIDE 结构断言：章节有非空 `id`/`title`，块 `type` 在合法集合内，各类型必填字段形状正确——防内容笔误导致静默不渲染。

## 验证

1. `node scripts/verify-help.mjs` 全绿（10 章、29 块）。
2. `pnpm build` 通过；`npx prettier --check` 涉及文件全过。
3. chrome-devtools 走查：
   - 主页面「操作手册 ▸」打开弹层，10 章全渲染、导航点击滚动定位正确、关闭回主页面。
   - 风水罗盘「？」打开帮助定位当前模式章节（定向/消砂均验证：章节视口顶 132px）；罗盘仍在下方（z-50 覆盖 z-40）。
   - 窄屏（~479px，触发 max-width:600px）无横向溢出、导航横向可滚动。
   - 控制台无错误。

## 范围边界（本版不做，记录备后续）

1. **术语深度**——一句话大白话解释，不做体系考证（各算法口径已有独立设计文档）。
2. **不在盘面标注术语**——本版只在帮助页集中解释，不改罗盘盘面渲染。
3. **不做按模式悬浮提示（tooltip）**——集中帮助页，留后续。
4. **无快捷键/Esc 关闭**——沿用项目现状（各弹层均按钮关闭）。
