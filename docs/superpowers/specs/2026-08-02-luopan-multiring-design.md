# 多圈罗盘读盘地基（P1）设计文档

日期：2026-08-02
状态：已与用户头脑风暴收敛并批准

## 背景与目标

现有风水罗盘（`src/components/fengshui/Luopan.vue`）功能完整（玄空飞星定向断宅），但视觉简单——只有地盘正针 24 山 + 后天八卦两圈，与真实罗盘的「多圈细密」观感差距大。用户希望罗盘**既酷又能干真罗盘的活**：多圈同心环 + 十字线读盘 + 按功能模式只显示需要的圈。

经讨论确认总目标：一张**能干活的多圈综合罗盘**（三合 + 三元 + 易卦 + 择日都在一张盘上）。整体分解为四个阶段，本文档为 **P1 读盘地基**：

- **P1 地基**：全圈数据层 + 模式系统 + 十字线读盘结构 + 读数面板 + 打通「定向」模式接现有玄空飞星。
- **P2 立向精度**：六十甲子分金 + 分金吉凶断语（叠进定向模式）。
- **P3 三合判断**：二十八宿消砂（人盘中针 + 赖公砂法）、纳水（天盘缝针 + 双山五行）判断算法 + 断语。
- **P4 易卦 + 择日**：六十四卦抽爻换象；节气 + 六十甲子择日。

## 决策摘要

| 决策点 | 结论 |
|---|---|
| 形态 | 现有 Luopan 升级为多圈旋转内盘，保留全部交互（拖拽/点按/手机传感） |
| 圈密度 | **模式驱动显示**：切功能模式 = 换圈集 + 换读数面板 + 换判断区；后天八卦常驻 |
| 读数机制 | 顶部红针升级为**天心十道（固定十字线）** + 盘心天池红线；读数以十字线为准，读数面板一行读出 |
| 模式范围 | P1 五个模式全开、全部可读数；仅「定向」接现有玄空判断，其余判断区占位（P2/P3/P4 补齐） |
| 数据 | 全圈静态数据一次建好（三盘/节气/度数/二十八宿/六十甲子/六十四卦方位） |
| 复用 | 先天六十四卦圆图排序逻辑从 `HexagramSquareCircle.vue` 抽出共享 util，卦数据复用 `hexagrams.js` |

## 数据设计

### 三盘三针（扩展 `src/data/luopan.js`）

现有 `mountains`（24 条，地盘正针，`{ name, palace, dragon, yinYang, angle }`）保留不动。新增两盘，同为 24 山、各带自己的角度：

- 人盘中针（消砂用）：相对地盘正针整体偏移 **−7.5°**。
- 天盘缝针（纳水用）：相对地盘正针整体偏移 **+7.5°**。

> 偏移方向以三合盘标准口径为准，实现时对照权威盘式核对正负号，由 `verify-fengshui.mjs` 断言固定。

### 二十四节气（扩展 `src/data/luopan.js`）

24 条，每 15°，冬至在 0°（子位），顺时针：

```
冬至(0°) 小寒(15°) 大寒(30°) 立春(45°) 雨水(60°) 惊蛰(75°) 春分(90°) 清明(105°)
谷雨(120°) 立夏(135°) 小满(150°) 芒种(165°) 夏至(180°) 小暑(195°) 大暑(210°) 立秋(225°)
处暑(240°) 白露(255°) 秋分(270°) 寒露(285°) 霜降(300°) 立冬(315°) 小雪(330°) 大雪(345°)
```

`{ name, angle, monthHint? }`（monthHint 可给约略公历月份，供择日读数参考，可选）。

### 周天度数（扩展 `src/data/luopan.js`）

helper 生成 360 刻度：每 1° 细线，15° 主刻度，90° 大字（0/90/180/270 标数字）。作为 `ticks` 型圈数据。

### 二十八宿（新增 `src/data/mansions.js`）

28 宿，四象七宿，各带宿度与五行。用于消砂（P3 判断，P1 先供读数）：

```
东方青龙：角 亢 氐 房 心 尾 箕
南方朱雀：井 鬼 柳 星 张 翼 轸
西方白虎：奎 娄 胃 昴 毕 觜 参
北方玄武：斗 牛 女 虚 危 室 壁
```

每条 `{ name, xiang(象), degree, wuxing }`。宿度非均匀（如角 12°、亢 9°…），以权威二十八宿度数表为准，度数和约 360°（含少度/附星口径在 verify 脚本内注明）。

### 六十甲子（新增 `src/data/jiazi.js`）

60 条，每 6°，从 甲子 在 0°（子位）起，含纳音五行：

```
甲子 乙丑 丙寅 丁卯 … 癸亥
海中金 海中金 炉中火 炉中火 …
```

`{ name, nian(纳音), angle }`。供择日读数（P1）与分金（P2）。

### 六十四卦方位（新增 `src/utils/fuXiOrder.js`）

把 `HexagramSquareCircle.vue:88-122` 的先天卦序逻辑（`fuXi` = 按 binary 数值升序排序；圆环 64 卦从乾(顶)左半逆时针到复、坤(底)右半顺时针到剥）抽成共享 util：`fuXiOrder(): { name, binary }[]`（圆环角度序）。卦内容复用 `src/data/hexagrams.js`。卦环「易卦」模式（P1 读数、P4 抽爻）与挂图方图共用同一份排序，保证一致。

### 模式 → 圈集映射（新增 `src/data/luopanRings.js`）

圈配置与映射全部数据化：每个圈 `{ id, type, radius, content }`，模式 → `ringIds[]`。

| 模式 | 圈集 | 读数面板 | 判断区 |
|---|---|---|---|
| 定向（默认） | 后天八卦 + 地盘正针 + 节气 + 度数 | 山·度·节气，坐/向两端都读 | 现有玄空飞星 |
| 消砂 | 后天八卦 + 人盘中针 + 二十八宿 + 度数 | 人盘山·宿度 | P3 上判断（占位） |
| 纳水 | 后天八卦 + 天盘缝针 + 度数 | 天盘山·水口 | P3 上判断（占位） |
| 择日 | 后天八卦 + 节气 + 六十甲子 | 节气·甲子·纳音 | 读数即可 |
| 易卦 | 后天八卦 + 六十四卦 + 度数 | 坐向卦名 | P4 上抽爻（占位） |

- **后天八卦常驻**（真罗盘上先天/后天八卦是常驻圈）。
- 半径：后天八卦 ~145、内容圈 ~172/196、度数圈 ~216–232（最终值实现时按可读性调，设计只定相对堆叠）。

## 组件结构

```
FengShuiView.vue          ← 已有：控制区 + 飞星盘 + 解读区 + 新增【模式开关】【读数面板】
 └─ Luopan.vue            ← 组合根：SVG、盘面旋转 <g>、十字线、天池、拖拽/点按/传感（全部保留）
     └─ RingLayer.vue     ← 新增：通用圈渲染器，type ∈ ticks/labels/glyphs，接圈配置数组
```

- **RingLayer.vue**：通用圈渲染器。`content` 为 `{ angle, text?, glyph?, binary?, sub? }[]`，按角度定位。`type`：
  - `ticks`——度数刻度
  - `labels`——文字标签（山名/节气/甲子/二十八宿）
  - `glyphs`——符号（卦爻 HexLines 或卦名）
- 加新圈 = 加一条圈配置，不改盘面交互逻辑。
- `HexagramSquareCircle.vue` 改为从 `fuXiOrder.js` 取序（重构，不改变现渲染结果）。

## 交互与读数

- **交互不变**：拖拽转盘、点按选山、手机传感跟随，三条路原封不动。
- **天心十道**：固定十字线穿盘心（细金线），竖线顶端=向（午）、底端=坐（子），横线读东/西。
- **天池**：盘心圆 + 子午红线；传感运行中保留现有水平气泡。
- **读数面板**（FengShuiView 控制区，替换现有「坐X朝Y」）：十字线处一行读出当前模式全部圈值。示例（定向）：`坐子 · 向午 · 0°/180° · 冬至/夏至`。
- Luopan 在 rot 变化（节流）时 emit 读数对象，FengShuiView 渲染。定向模式读数同时驱动现有 `selectedDir` → 玄空链路。

## 阶段边界（P2/P3/P4 只列方向，不入本 spec）

- **P2**：120 分金（每山 5 分金）数据 + 分金吉凶（孤虚/旺相/空亡/龟甲）断语，叠进定向模式。
- **P3**：二十八宿消砂（人盘中针 + 赖公砂法）、纳水（天盘缝针 + 双山五行）判断算法 + 断语。
- **P4**：六十四卦抽爻换象；节气 + 六十甲子择日输出。

## 验证

1. `scripts/verify-fengshui.mjs` 追加数据不变量：
   - 三盘偏移 ±7.5°、各 24 山、角度连续；
   - 节气 24 × 15°、冬至在 0°；
   - 六十甲子 60 × 6°、从甲子 0° 起；
   - 二十八宿 28 条、度数合计 360°（注明口径）；
   - 先天卦序 64 卦唯一、与 `HexagramSquareCircle` 现有渲染顺序一致。
2. 现有玄空回归（五/七/八/九运案例）不回归。
3. `pnpm build` + `npx prettier --write <涉及文件>` 后 `--check`。
4. UI 走查（`pnpm dev`）：
   - 五模式切换：圈集随模式换、后天八卦常驻；
   - 十字线读数随转盘实时更新；传感跟随下读数 = 手机朝向；
   - 定向模式 → 飞星盘/解读区链路不变；
   - 移动端（≤600px）盘面不超宽、圈内文字可辨、正文可滚动。
