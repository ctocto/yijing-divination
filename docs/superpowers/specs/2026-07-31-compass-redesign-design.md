# 易经占卜 UI/UX 重设计 — 古典东方美学罗盘

> 状态：已获用户批准（2026-07-31）
> 前置文档：`易经占卜程序设计.md`（功能规划来源）

## 背景

当前应用有两个页面（首页罗盘图 + 占卜页），视觉风格不统一（首页浅色/占卜页暗色），交互简单（点击按钮随机生成卦象），未充分利用罗盘作为占卜器具的仪式感。设计文档 `易经占卜程序设计.md` 中规划的梅花易数、历史记录等功能尚未实现。

本次重设计聚焦于：以罗盘为交互中心的单页古典东方美学体验，为后续功能扩展奠定统一的视觉和交互基础。

## 设计目标

- 统一为古典东方美学风格（宣纸、朱砂、墨色、毛笔字韵）
- 罗盘作为唯一的交互中心，消除页面跳转
- 转罗盘触发占卜，仪式感优先
- 64 卦环形围绕罗盘，八宫扇区分组，可浏览可占卜
- 动效克制沉稳，墨迹晕开风格
- 结果以卷轴一镜到底展开，完整展示卦辞爻辞

## 二、页面架构

### 从两页合并为单页

- **路由变更**：删除 `/divination` 路由，`/` 承载全部功能
- **新增 Vue composable**：`src/composables/useCompass.js` 管理全局状态

### 三大状态（状态机）

```
闲观态 ──转盘──▶ 占卜态 ──出卦──▶ 阅读态
  │                  │                  │
  └──点击卦象───────┘                  │
     (浏览详情)                         │
                    点「再起一卦」回到闲观态 ◀──┘
```

| 状态 | 罗盘位置 | 显示内容 |
|------|----------|----------|
| 闲观态 | 全屏居中 | 罗盘 + 64 卦图环，可转盘或浏览 |
| 占卜态 | 全屏居中，旋转中 | 罗盘旋转动画 |
| 阅读态 | 左上角缩小至 160px | 卷轴展开，占卜结果 |

### Composable 状态设计 (`useCompass`)

```js
// src/composables/useCompass.js
state: 'idle' | 'spinning' | 'reading'
rotation: number           // 当前旋转角度（度）
selectedHexagram: object | null  // 点击浏览的卦象
divinationResult: object | null  // 占卜结果
direction: string          // 问题方向（事业/情感等）
```

## 三、罗盘布局（同心环结构）

罗盘主体占视口短边 90%，最大直径约 700px（桌面端）。

```
┌─────────────────────────────────┐
│  ④ 卦图环：8 扇区 × 8 卦 = 64 卦  │  最外层，可点击浏览
│  ┌───────────────────────────┐  │
│  │  ③ 刻度环：天干地支五行标注   │  │  装饰/知识层，不可交互
│  │  ┌─────────────────────┐  │  │
│  │  │  ② 罗盘面：卦位指针   │  │  │  转盘交互区，随拖拽旋转
│  │  │  ┌───────────────┐  │  │  │
│  │  │  │ ① 中心太极    │  │  │  │  视觉锚点，静止
│  │  │  └───────────────┘  │  │  │
│  │  └─────────────────────┘  │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
```

### ① 中心太极
- 直径约 80px，静止不动
- 双击可快速回到闲观态

### ② 罗盘面（交互核心）
- 直径约 350px
- 朱砂色指针固定在 12 点方向
- 8 条方位线指向扇区
- 盘面回字纹/云纹装饰
- 拖拽旋转，带惯性减速

### ③ 刻度环
- 固定不动
- 8 个宫位名 + 五行属性 + 天干地支简标
- 复用已有 `HexagramChart.vue` 刻度数据

### ④ 卦图环
- 64 个卦符分 8 组（八宫），排列在 8 个扇区
- 每卦符约 40×30px 小卡片：卦名 + 三横线简图
- 点击卦符：朱砂高亮 + 侧边浮出卦名简释标签
- 占卜出卦：对应卦符朱砂脉冲动效
- 扇区间金线分隔

## 四、卷轴结果页面（阅读态）

### 布局

卷轴在罗盘缩小后展开于主区域，竖向一镜到底，超出视口可滚动。

### 内容结构（从上到下）

1. **问题方向选择器**：下拉框，与现有 `direction` 字段对接
2. **卦符图**：六条爻线，墨色粗线/断线，约 60px 宽，居中
3. **卦名**：朱砂色 `#c0392b`，48px，毛笔字体
4. **卦辞**：墨色，18px，居中
5. **爻辞**：墨色，15px，逐条，朱砂圆点标记
6. **白话解读**：淡墨色，14px
7. **「再起一卦」**：朱砂印章样式按钮

### 视觉细节

- 卷轴背景 `#faf6ed`，左右淡木轴色竖线模拟装裱轴头
- 卷轴展开动效：clip-path 从上到下 0.8s，内容逐行错开淡入（stagger 60ms）
- 卷轴收起：clip-path 从下到上 0.4s，罗盘同时滑回中心

## 五、交互动效

### 罗盘旋转
- 拖拽跟手：`mousedown`/`touchstart` 记录角度 → `mousemove`/`touchmove` 实时 `transform: rotate()`
- 松手惯性减速：`cubic-bezier(0.2, 0, 0.1, 1)`，1.5~3s 自然停止
- 停止后角度在卦位 ±2° 内自动吸附
- 旋转 <15° 且极低速：不触发占卜，视为误触

### 出卦判定
- 旋转完全停止后，指针所指扇区为所得宫位
- 宫位 8 卦中随机取一卦

### 卦象高亮
- 朱砂色脉冲：`@keyframes` 缩放 1→1.15→1，两次，每次 0.4s
- 罗盘指针短暂闪烁同步

### 浏览交互
- 点击卦符：淡金背景亮起 + 标签淡入 0.25s
- 标签内容：卦名 + 卦辞首句，约 120px 宽
- 点击空白/其他卦：标签淡出

### 状态转场
- 闲观→占卜：直接进入旋转
- 占卜→阅读：罗盘缩小滑向左上角 0.6s + 卷轴展开 0.8s（0.1s 重叠）
- 阅读→闲观：卷轴收起 0.4s + 罗盘滑回放大 0.5s（0.1s 重叠）

## 验证方式

1. `pnpm dev` 启动开发服务器，浏览器打开
2. 验证闲观态：罗盘全屏居中，64 卦环绕可见
3. 拖拽罗盘：跟手旋转，松手惯性停止

5. 卷轴：滚动查看完整卦辞爻辞解读

7. 点击任意卦符浏览：标签浮现，点击别处消失
8. 方向选择器可切换问题方向
