# 罗盘 · 精确天文节气（替换择日近似节气表）设计文档

## 背景与目标

Phase 2（择日日历）用**近似节气表**定月建（边界 ±1 天），当时已注明精确节气留后续。本次换**精确天文计算**：太阳视黄经反推 12 节交节日期，月建精确到日。

已查证的关键差异：**2024 清明实为 4/4**（近似表给 4/5），精确后 4/4 即换辰月；**2025 立春实为 2/3**（硬编码年界 2/4），精确后 2/3 即乙巳年。

## 算法（已查证 Meeus/NOAA 低精度太阳视黄经）

### 太阳视黄经（精度 ~0.01° ≈ 15 分钟）

```
T = (JD - 2451545.0) / 36525
L0 = 280.46646 + 36000.76983*T + 0.0003032*T²           平黄经
M  = (357.52911 + 35999.05029*T - 0.0001537*T²)·π/180    平近点角
C  = (1.914602 - 0.004817*T - 0.000014*T²)·sin M
   + (0.019993 - 0.000101*T)·sin 2M + 0.000289·sin 3M    中心差
Θ  = L0 + C                                               真黄经
Ω  = (125.04 - 1934.136*T)·π/180
λ  = Θ - 0.00569 - 0.00478·sin Ω                         视黄经（光行差 + 章动）
```

### 节气与黄经

- 24 节气 = λ 每 15° 对应时刻。12 节（月建）黄经：立春315 惊蛰345 清明15 立夏45 芒种75 小暑105 立秋135 白露165 寒露195 立冬225 大雪255 小寒285。
- 求交节：初值用平黄经反推（距 1/1 天数），Newton 迭代（dλ/dt≈0.9856°/日）至 <1e-5°，年份归位（±365.2422 平移重算）。
- 时区固定 UTC+8（北京时间）。**月建以交节所在日历日换月**（择日为日期输入，不细分交节时辰）。

## 实现

### `src/utils/ganzhi.js`（+ `.d.ts`）

- **删除**近似 `JIE_ZHI` 表。
- 新增（纯函数，node 可校验）：
  - `sunLongitude(jd)` → 太阳视黄经（0-360）。
  - `localJd(y,m,d,hour)` = `jdn(y,m,d) - 0.5 + (hour-8)/24`（复用现有 `jdn`）。
  - `jdToLocalDate(jd)` → `{y,m,d}`（UTC+8，Fliegel-Van Flandern 逆算法）。
  - `jieMoment(year, lon)` → 该年该黄经交节 `{y,m,d}`（节或气均可）。
  - `jieZhi(y,m,d)` 重写：12 节各 `jieMoment(y, lon)` + 兜底 `jieMoment(y-1, 255)`（大雪，1 月初），取最晚 ≤ 日期的交节之支。
  - `yearGanZhiAt(y,m,d)` 重写：年界 = `jieMoment(y, 315)`（精确立春），立春前归上年。
- `ganzhiOf` / `monthGanZhi` / `judgeZeriByDate` 无需改动。

## 范围边界（本版不做，记录备后续）

1. **交节时刻（时分）级精确**——本版只精确到交节日；低精度公式时刻精度约 ±30 分钟，月建/年界不细分时辰（日期输入口径）。
2. **其余 12 气（春分/谷雨/…）日历化展示**——本版只用于月建与年界；`jieMoment` 已支持任意黄经，留后续展示 24 节气交节日历。
3. **天文历书权威时刻（紫金山天文台逐分钟）**——低精度公式与历书日期级一致（误差 ≪ 1 天），时刻级差异约 ±半小时。
4. **农历（月相/置闰）**——干支系统不依赖农历，仍只到干支纪年/月/日。
