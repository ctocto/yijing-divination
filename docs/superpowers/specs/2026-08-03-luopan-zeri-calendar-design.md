# 罗盘择日 · 日历对接 + 干支纪年（Phase 2）设计文档

日期：2026-08-03
状态：已与用户确认口径（月建用近似节气表，±1 天；干支纪年/纪日精确；天文精确节气留后续）

## 背景与目标

优先级计划 Phase 2（最高价值：择日从「演示」变「实用」）。当前择日模式是**读盘直断**——用十字线的节气/甲子当日期（`judgeZeri(readout.term, readout.jiazi)`），不真实。本次加**真实日期输入**：公历 → 年/月/日干支 → 建除/黄道/纳音，让用户能真正选吉日。

**用户已拍板**：月建用**近似节气表**（边界 ±1 天，文化参考足够），干支纪年/纪日用**精确公式**，天文精确节气留后续。

## 算法口径（已查证）

### 干支纪日（精确）

- `日干支序 = (JDN + 49) mod 60`（甲子=0）。JDN 用格里历标准算法（`d + ⌊(153m'+2)/5⌋ + 365y' + ⌊y'/4⌋ − ⌊y'/100⌋ + ⌊y'/400⌋ − 32045`，m' = m+12·⌊(14−m)/12⌋−3，y' = y+4800−⌊(14−m)/12⌋）。
- 已核验：1949-10-01 = 甲子（开国大典）、2000-01-01 = 戊午、1791-02-11 = 甲申。
- 公式仅适用 1582-10-15 起的格里历；择日实际日期都在此范围。

### 干支纪年（精确 + 立春年界）

- `((y−4) mod 60 + 60) mod 60`（1984 = 甲子）。
- **立春（2/4）为年界**：立春前仍属上年（2000-01-01 是己卯年而非庚辰年；2024-02-03 是癸卯年，02-10 才是甲辰年）。

### 月建支（近似节气表，±1 天）

- 12 节近似公历日 → 月支（标准俗节气口径）：
  `小寒1/5丑 立春2/4寅 惊蛰3/5卯 清明4/5辰 立夏5/5巳 芒种6/5午 小暑7/7未 立秋8/7申 白露9/7酉 寒露10/8戌 立冬11/7亥 大雪12/7子`
- 取「最晚 ≤ 日期」的节；1/1-1/4 归上一轮大雪 → 子月。
- **边界 ±1 天误差**（节当日随年份浮动 1-2 天），已与用户确认接受；精确天文节气留 Phase 后续。

### 月干（五虎遁）

- `甲己丙作首、乙庚戊为头、丙辛庚起、丁壬壬、戊癸甲`（寅月起，月干按干序顺排）。

## 算法设计

### 新增 `src/utils/ganzhi.js`（+ `.d.ts`，纯函数，node 可校验）

- `jdn(y, m, d)` → 儒略日数（格里历）。
- `dayGanZhi(y, m, d)` → `{ name, nian }`：`(jdn+49)%60` → 查 `jiazi`。
- `jieZhi(y, m, d)` → 月建支（近似节气表）。
- `yearGanZhiAt(y, m, d)` → `{ name, nian }`：立春前用 `y-1`。
- `monthGanZhi(yearGan, monthZhi)` → 月干支名（五虎遁）。
- `ganzhiOf(y, m, d)` → `{ year, month, day }` 聚合（day 含 nian）。
- 局部表：`JIE_ZHI`、`WU_HU_DUN`、`GANS`、`BRANCHES`。

### `src/utils/zeri.js`（+ `.d.ts`）新增

- `judgeZeriByDate(y, m, d)` → `{ yearGz, monthGz, dayGz, monthB, dayB, jianChu, huangDao, nian }`：`ganzhiOf` + 现有 `jianChuIndex` / `jianChu` / `huangDao`。

## 组件设计（`src/components/fengshui/FengShuiView.vue` fs-zeri 区）

- 来源切换「日历 / 读盘」，默认**日历**（今天）：
  - **日历**：`<input type="date">`（默认今天）→ `judgeZeriByDate` → 「YYYY-MM-DD · 甲辰年 丙寅月 甲辰日（覆灯火）」+ 「寅月 · 辰日 · 满日（天刑 · 黑道）」+ 宜忌。
