# 罗盘分金·立向精度（P2）设计文档

日期：2026-08-02
状态：已与用户头脑风暴收敛并批准（用户选定：3° 吸附 · 只标 48 旺相圈 · 坐+向都断）

## 背景与目标

P1 多圈罗盘已落地（读盘地基），P3 消砂/纳水、P4 易卦/择日已合入 main。P1 路线图中 **P2 立向精度**：120 分金 + 分金吉凶断语，叠进定向模式——一直未做。本文档实现 **P2 分金**：

- 定向模式新增一圈**只标 48 旺相**的 120 分金盘（每山 5 槽 × 3°，孤虚/龟甲留空，如真罗盘）。
- 拖拽吸附粒度 15° → **3°**（分金槽中心），读出坐/向各自分金名 + 纳音 + 吉凶（旺相/孤/虚/龟甲/空亡）+ 断语。
- 现有玄空飞星链路（山名级）**不动**，分金作并列判断叠进定向模式。

## 算法口径（已查证，主流三合分金口径）

### 120 分金构成

二十四山每山均分 5 等份（每份 3°），24 × 5 = **120 分金**合 360°。每槽一个六十甲子名（含纳音），命名有规律：

- **分金地支**：每山用「前一位地支山」的地支（二十四山序中紧邻其逆时针方向的地支山；地支山本身用自己）：
  ```
  子→子 癸→子 丑→丑 艮→丑 寅→寅 甲→寅
  卯→卯 乙→卯 辰→辰 巽→辰 巳→巳 丙→巳
  午→午 丁→午 未→未 坤→未 申→申 庚→申
  酉→酉 辛→酉 戌→戌 乾→戌 亥→亥 壬→亥
  ```
  （如巽山循辰山、壬山循亥山；与旺相表 48 条一致：巽山旺相=丙辰/庚辰、壬山=丁亥/辛亥。）
- **干序**：按分金地支阴阳隔位排——
  - 阳支（子寅辰午申戌）：`甲 丙 戊 庚 壬`
  - 阴支（丑卯巳未酉亥）：`乙 丁 己 辛 癸`
- **槽位**：每山 5 槽，槽中心 = 山中心 −6° + 3i（i=0..4），5 槽铺满整山 ±7.5°。子山（中心 0°）五槽：甲子(354°)、丙子(357°)、戊子(0°)、庚子(3°)、壬子(6°)。

### 分金吉凶（纳甲口诀）

> 甲壬阳孤乙癸虚，龟甲空亡戊己推，丙丁庚辛虽旺相。

| 槽位 | 天干 | 判 | 吉凶 |
|---|---|---|---|
| 第 2/4 槽（中线旁 ±3°） | 丙丁庚辛 | **旺相** | 吉 |
| 第 1 槽（靠壬山侧 ±6°） | 甲 / 乙 | **孤 / 虚** | 凶 |
| 第 5 槽（靠癸山侧 ±6°） | 壬 / 癸 | **孤 / 虚** | 凶 |
| 第 3 槽（坐山正中） | 戊 / 己 | **龟甲** | 凶 |
| 两山交界线（骑缝） | — | **空亡** | 凶 |

- 旺相每山 2 个、共 **48** 个可用；孤 24、虚 24、龟甲 24、骑缝空亡不计槽。真罗盘只标 48 旺相，其余留空。
- **坐向对称**：坐向差 180°，同天干同判（丙子坐 → 丙午向，均旺相），坐向吉凶天然一致。

## 数据设计

### `src/data/fenjin.js`（新增）+ `.d.ts`

120 分金**由规则生成**（不手写 120 条），导出：

- `FENJIN_ZHI`：24 山 → 分金地支 映射表（见上）。
- `GAN_SEQ`：`{ 阳: ['甲','丙','戊','庚','壬'], 阴: ['乙','丁','己','辛','癸'] }`。
- `fenjin120`：120 条 `{ mountain, index(0-4), angle, name, gan, zhi, level, nian }`。`level` 按天干：丙丁庚辛→旺相、甲壬→孤、乙癸→虚、戊己→龟甲；`nian` 由 `name` 查 `jiazi.js`。
- 派生 `wangXiang48`：`level === '旺相'` 的 48 条（盘面只标这批）。

### `src/utils/fenjin.js`（新增）+ `.d.ts`（纯函数，node 可校验）

- `fenjinAt(deg)`：到最近 15° 交界线（角度 ≡ 7.5 mod 15）的**循环距离 < 0.5°** → 骑缝空亡 `{ type:'kongwang', a, b }`（两侧山名）；否则落在槽内 → 该槽对象 `{ mountain, index, angle, name, gan, zhi, level, nian }`。注：3° 吸附落点恒为槽中心、触及不到骑缝，空亡仅传感连续角度可达。
- `judgeFenjin(deg)`：坐 = deg、向 = deg + 180，各取 `fenjinAt`，返回 `{ shan, xiang }`，每侧 `{ mountain, name, gan, zhi, level, nian, ji, text }`。`ji` = 旺相→'吉' 否则 '凶'；`text` 按 level：
  - 旺相：`旺相分金，可立向。`
  - 孤：`阳孤分金，孤阳不生，不宜立向。`
  - 虚：`阴虚分金，独阴不长，不宜立向。`
  - 龟甲：`龟甲空亡，坐向正中一线，不宜立向。`
  - 空亡：`骑缝空亡，两山交界之线，不宜立向。`

## 盘面与交互设计

### 盘面（`luopanRings.js` + `Luopan.vue`）

- `modeRings.ding` 插入 `'fenjin'`：`{ type:'labels', radius: 212, labelSize: 10 }`（地盘 198 与度数 220 之间，合真罗盘序）。items 只取 `wangXiang48`，当前十字线落点若是旺相槽则该标签高亮（`active`）。
- `Luopan.ringItems` 加 `'fenjin'` case。

### 交互（立向精度）

- **吸附粒度**：`onUp` 吸附步长按模式——定向 **3°**，其余模式仍 15°。点按选山仍吸附山中心（= 龟甲，语义正确）。
- **传感锁定保精度**：新增 `fine-angle` prop（定向模式持有）。`fineAngle != null` 时 Luopan 位置 = 该角度（不再回弹山中心）；手机朝向锁定后保持分金朝向。
- **模式归位**：离开定向模式 `fineAngle = null`，盘面归位山中心，不污染消砂/纳水/择日/易卦等粗粒度模式（它们仍按山名逻辑）。
- 传感运行中分金随手机朝向实时更新（角度本就连续）。

### 读数面板 + 判断区（`FengShuiView.vue`）

- 读数面板（定向）：`坐子·丙子(旺相) · 朝午·丙午(旺相)`（由 `judgeFenjin(readout.angle)` 取坐/向）。骑缝空亡时该侧显示 `骑缝(空亡)` 无分金名。
- 判断区新增「分金吉凶」section（fs-pan 与 fs-reading 之间）：
  ```
  ┌─ 分金吉凶 ────────────────────────┐
  │ 点按居中即正向·龟甲，拖拽微调至旺相分金 │
  │ 坐分金：丙子（涧下水）· 旺相 · 吉      │
  │   —— 旺相分金，可立向。              │
  │ 向分金：丙午（天河水）· 旺相 · 吉      │
  │   —— 旺相分金，可立向。              │
  └───────────────────────────────────┘
  ```

1. `scripts/verify-fengshui.mjs` 追加断言：
   - `fenjin120` 共 120 条、每山恰 5 条、角度无缝铺满 360°（排序后相邻差恒 3°）；
   - `wangXiang48` 恰 48 条、全为旺相；level 分布 旺相48 / 孤24 / 虚24 / 龟甲24；
   - 天干不变量：旺相仅丙丁庚辛、孤仅甲壬、虚仅乙癸、龟甲仅戊己；

## 范围边界（P2 明确不做，记录备后续）

1. **分金配仙命纳音生克**（阴宅立穴按仙命断刺穴煞等）——本版只断分金自身吉凶，不接生辰。
2. **兼向/替卦对玄空的影响**——玄空仍按山名（15°）算，分金为并列判断不参与下卦/替卦；用户已确认此口径。
3. **其他立向体系**——七十二穿山虎、六十透地龙等不做。
4. **分金与易卦抽爻结合**（P4 spec 已记）——抽爻换象配分金定卦气留后续。
