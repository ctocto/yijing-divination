# 罗盘易卦抽爻·玄空大卦 + 分金配仙命（Phase 1）设计文档

日期：2026-08-03
状态：已调研主流口径并经用户批准（易卦 = 玄空大卦抽爻换象「线压爻动」；仙命 = 纳音五行生克）

## 背景与目标

用户按性价比排出罗盘专业功能 Phase 1 两项，本版实施：

1. **分金 × 易卦抽爻结合**（P4 spec 记「留后续」、P2 spec 记「抽爻换象配分金定卦气留后续」）。
2. **分金配仙命纳音生克**（P2 spec 记「需生辰输入，不做」）。

要求**参考流行做法**实现。已调研玄空大卦抽爻换象与仙命配分金主流口径，方案据此确定。

现状：易卦模式是「十字线读本卦（先天六十四卦环）+ 手动点选动爻 → 爻辞/变卦辞断语」；定向分金区只有分金自身吉凶。

## 算法口径（已查证，主流玄空大卦 / 三合口径）

### 玄空大卦抽爻换象

- 360° 均分 384 爻（64 卦 × 6 爻，**每爻 0.9375°**）；坐向线（十字线）压哪一爻、哪一爻即「动」，动爻阴阳翻转得变卦——**线压爻动 = 自动抽爻**。
- **卦气吉凶**：变卦内外卦按「先天配洛书数」`乾9 兑4 离3 震8 巽2 坎7 艮6 坤1`（与后天卦配洛书 `坎1坤2震3巽4乾6兑7艮8离9` 是两套系统，取前者）：
  - 合五（一四、二三）、合十（一九、二八、三七、四六）、合十五（六九、七八）、生成数（一六共宗、二七同道、三八为朋、四九为友）→ **吉**（合数主旺财、生成数主旺丁）；
  - 不合数理 → 兼看内外卦五行生克，相克 → **凶**，否则平。
- 文献实例：履（上乾9下兑4）四九为朋吉；益（上巽2下震8）合十吉；否（上乾9下坤1）合十吉；大有（上离3下乾9）不合数理且火克金凶。

### 仙命配分金（仙命为主、分金为从）

- 分金纳音五行与仙命纳音五行论生克：**分金生仙命（生入）/ 比和（旺）/ 仙命克分金（财）→ 吉**；**仙命生分金（泄出）/ 分金克仙命（杀/克入）→ 凶**。
- 分金吉凶口诀「甲壬阳孤乙癸虚，龟甲空亡戊己推，丙丁庚辛虽旺相」与现有 `LEVEL_BY_GAN` 一致，无需改动。

## 算法设计

### `src/utils/yijing.js`（新增纯函数 + `.d.ts`）

- `yaoAt(deg)` → `{ name, binary, index }`：复用 `fuXiRing`（卦中心 5.625° 扇区），扇区内均分 6 爻（每爻 0.9375°），`off` 归一至 (-STEP/2, STEP/2] 后 `index = clamp(floor((off + STEP/2)/STEP*6), 0, 5)`。简化口径：初爻居卦位起角、上爻止于终角。
- `judgeGuaQi(binary)` → `{ upper, upperNum, lower, lowerNum, rel, ji, text }`：`binary.slice(0,3)`=下卦、`slice(3,6)`=上卦，查 `XUAN_KONG_LUO` → 合五/合十/合十五/生成数 → 吉；不合数理用 `trigrams.wuxing` 判相克 → 凶，否则平。
- 局部表：`XUAN_KONG_LUO`、`TRIGRAM_BIN`（3 位 → 卦名）、`SHENGCHENG`（生成数对）。

### `src/utils/fenjin.js`（新增纯函数 + `.d.ts`）

- `yearGanZhi(year)` → `{ name, nian }`：`idx = ((year-4)%60+60)%60`（1984=甲子），查 `jiazi`。
- `nianWuxing(nian)` → 五行：纳音名末字（海中金→金、涧下水→水…）。
- `judgeXianMing(year, fenjinNian)` → `{ relation, ji, text }`：仙命为体、分金为用，五段生克（局部 `SHENG`/`KE` 表）。
- `XIAN_MING_META`：生/旺（比和）/财 → 吉；泄/杀 → 凶（断语文案）。

## 范围边界（本版不做，记录备后续）

1. **爻位顺/逆排真实规则**（内外卦阴阳：同性相遇逆排、阴阳相配顺排）——只影响「初爻起始角」这一数据方向，不改变「线压爻动」核心交互；派别口径有出入需逐卦核对，先统一简化口径。待后续严谨化时补方向表。
2. **卦运**（下卦爻变定江东/江西运 + 与当前元运比同元）——独立判断维度，需新增元运对照逻辑，属玄空大卦第二步深化。
3. **珠宝线 / 红点吉爻标记**（九星挨星各取爻位）——依赖九星挨星子系统（另一套数据）；且文献明言「抽爻后新卦合十才为珠宝线」，即以卦气判断为先导，卦气未落地前无从谈起。
4. **兼线分金（双爻同抽）**——仅单爻抽不出吉象时用于 8 个特殊卦（夬/井/涣/谦/剥/噬嗑/丰/履）；把动爻模型从单爻变双爻，UI 高亮/变卦翻转/红点标记全变，属进阶技法。
5. **玄空大卦与玄空飞星对接（下卦/替卦）**——用户已确认玄空仍按山名 15° 口径，分金为并列判断、不参与下卦/替卦；接卦线判替卦改动飞星链路影响面大。
6. **仙命输入用出生年而非完整生辰**——主流仙命配分金只取年柱纳音，月/日/时柱不参与；完整八字输入增加 UI/校验复杂度且无收益。
