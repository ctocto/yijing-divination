# 易经占卜 首页精致化重做 — 设计规格

> 状态：已获用户批准（2026-08-01）
> 前置文档：`2026-07-31-compass-redesign-design.md`（上一版罗盘设计，本版在其基础上精致化重做）
> 设计系统来源：ui-ux-pro-max（纸感 E-Ink/Paper 风格 + 墨黑/朱砂/金线配色 + 毛笔/宋体字阶）

## 背景

当前首页为「古典罗盘挂图」风：宣纸底、整屏大罗盘、64 卦环绕，靠拖拽转盘占卜。用户认可古典罗盘概念本身，但认为执行质量不足（布局像挂图、信息层级弱、交互门槛高、移动端粗糙）。本次在**概念不变**的前提下，按专业标准精致化重做：视觉系统、页面架构、交互反馈、移动端全部重做。

## 设计目标

- 罗盘仍是主角，但首页从「一张挂图」变成「一个真正的 App 首页」
- 新增低门槛起卦路径（点按起卦），保留拖拽转盘
- 信息层级清晰：品牌 → 罗盘 → 操作
- 出卦反馈有仪式感但不拖沓
- 移动端可用性达标

## 二、页面架构

### 闲观态（首页本体）—— 三段式

```
┌──────────────────────────────────────┐
│  易经占卜           [? 如何起卦]        │ ← AppHeader
├──────────────────────────────────────┤
│                                      │
│       ● 罗盘 + 64 卦环（主视觉）       │ ← CompassCore
│        （卦符点击 → 侧边详情面板）       │
│                                      │
├──────────────────────────────────────┤
│  所问何事 [事业 ▾]      [其他→输入框]   │ ← CastBar
│      ┌────────────────────┐          │
│      │    静 心 起 卦       │          │
│      └────────────────────┘          │
│           浏览六十四卦 ▸               │
└──────────────────────────────────────┘
```

- **顶栏 `AppHeader`**：左「易经占卜」毛笔标题；右「如何起卦」图标按钮 → `HowToOverlay` 弹层
- **中央 `CompassCore`**：罗盘 + 卦环主视觉，尺寸让出上下空间（占视口短边约 68%）
- **底部操作栏 `CastBar`**：方向选择（下拉 + 其他输入）→ 朱砂主按钮「静心起卦」→ 次级入口「浏览六十四卦」

### 卦库（浏览态）

点击「浏览六十四卦」→ 全屏 `HexagramLibrary` 网格视图：

- 64 卦按八宫分 8 组展示
- 每格 = 卦名 + 卦符（六爻简图），约 100×80px
- 点击 → `HexagramDetailPanel` 详情
- 顶部返回按钮 → 回闲观态

### 阅读态（结果页）

罗盘缩至左上角小徽标（约 160px，桌面端），卷轴居中：

- 结构：卦符 → 卦名 → 卦辞 → 爻辞 → 白话解读 → 朱砂「再起一卦」
- 方向选择已前置到起卦前，结果页**不再有下拉**
- 排版：居中卦名（毛笔 44px）、楷体小字、朱砂圆点爻辞、淡金分隔线、留白加大
- 移动端（≤600px）：罗盘隐藏，卷轴全屏，「再起一卦」按钮回闲观态

## 三、交互与反馈

| 入口 | 行为 |
|------|------|
| 拖拽转盘 | 保留：跟手 → 惯性 → 吸附宫位 → 出卦。新增：旋转中指针下方实时显示所向宫位名 |
| 点按起卦 | 新增：点「静心起卦」→ 罗盘自动旋转 2~3 圈（约 2.5s）→ 减速停止 → 出卦。仅闲观态可点，转盘旋转中禁用 |
| 出卦反馈 | 指针所向宫位金线亮起 → 该宫 8 卦符逐一朱砂点亮（每 120ms）→ 罗盘缩小 + 卷轴展开 |
| 浏览卦象 | 闲观态点卦符 → 右侧滑出详情面板（卦名/卦辞/所属宫/爻辞）；点空白关闭 |
| 卦库 | 「浏览六十四卦」→ 全屏网格；点击卦格 → 详情面板；返回 → 闲观态 |
| 误触保护 | 拖拽 <15° 且低速不占卜（保留） |

### 状态机（`useCompass` 扩展）

```
闲观 idle ──拖拽──▶ 旋转 spinning ──吸附──▶ 阅读 reading
    │  └──点按起卦──▶ 自动旋转 casting ──停──▶ 阅读 reading
    │  └──浏览卦库──▶ 浏览 browse ──返回──▶ 闲观
    └──────点击卦象──▶ 详情面板（idle 子状态）
```

新增字段/方法：

- `state` 新增 `'casting'`、`'browse'` 两个值
- `castSpin()`：自动旋转动画（约 2.5s，ease-out 减速），结束复用 `completeSpin()`
- `currentPalaceName`（computed）：由 `rotation` + `palaceIndexAt` 推导，旋转中实时显示
- `openLibrary()` / `closeLibrary()`：`state` 在 `'idle'` 与 `'browse'` 间切换
- 详情面板：复用现有 `selectedHexagram`，在闲观态（点卦环）与卦库态（点卦格）均为 overlay，关闭方式一致（点空白 / 再点同卦）

## 四、移动端适配

- 移动优先；底部操作栏 `CastBar` 在闲观态 sticky 底部
- 罗盘尺寸 `min(78vmin, …)`，Header/操作栏不遮挡
- 触摸目标 ≥44px；卦库网格 3 列自适应
- 阅读态罗盘隐藏，卷轴全屏 + 「再起一卦」
- 方向下拉在窄屏改为整行选择

## 七、验证方式

1. `pnpm dev` 启动，浏览器打开
2. 闲观态：顶栏 + 中央罗盘 + 底部操作栏三段式可见，罗盘不遮挡操作栏
3. 点「静心起卦」：罗盘自动旋转约 2.5s → 减速停 → 宫位金线亮 → 8 卦符逐一亮 → 罗盘缩小 + 卷轴展开
4. 拖拽转盘：跟手、惯性、吸附、出卦；旋转中指针下方显示所向宫位名
5. 阅读态：方向选择已前置（结果页无下拉），卷轴排版正确，可滚动，「再起一卦」回闲观态
6. 浏览：点卦符 → 右侧详情面板滑出，点空白关闭
7. 卦库：点「浏览六十四卦」→ 全屏网格 → 点击卦格 → 详情 → 返回
8. 移动端（≤600px 视口）：三段式无横向滚动，触摸目标 ≥44px，阅读态罗盘隐藏
9. `npx eslint .` 与 `npx prettier --check .` 通过
